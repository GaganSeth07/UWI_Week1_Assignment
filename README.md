# 📊 Student Marks - Basic Data Analysis (Pandas + Matplotlib)

## 📌 Project Overview
This project performs **basic data analysis** on a student marks dataset using **Python (Pandas + Matplotlib)**.

The analysis includes:
- Loading a CSV dataset using Pandas
- Descriptive statistics:
  - Mean
  - Median
  - Mode
  - Standard Deviation
- Data visualization:
  - Subject-wise histograms
  - Boxplot for outlier detection
  - Total marks distribution
- Performance analysis:
  - Top 10 students
  - Bottom 10 students

---

## 📑 Dataset Details
The dataset contains marks of **100 students** in the following subjects:
- Maths
- Science
- English
- Social Studies
- Language

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

=> Summary / Insights

- Average student performance is around 51%

- Science has the highest average marks

- Language has the lowest average marks

- Top 10 students scored around 67% to 79.6%

- No strong outliers were detected using the IQR method for total marks
